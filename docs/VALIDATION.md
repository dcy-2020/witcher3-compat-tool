本地 Windows 的符号链接创建测试可能因系统权限而跳过；明确记录为跳过，不能视为通过。Linux CI 可覆盖这条测试。GitHub Actions 定义 Windows/Linux × Python 3.10/3.12 矩阵；远端是否通过以仓库实际运行结果为准，定义矩阵本身不是通过证明。

本地最终测试：41 项，40 项通过，1 项因 Windows 符号链接创建权限跳过。wheel 构建成功。源码 ZIP、单文件 zipapp 的打包白名单、SHA-256 清单和实际 CLI 启动另行检查；不将构建成功视为游戏运行验证。

首次公开源码提交的 [GitHub Actions 运行](https://github.com/dcy-2020/witcher3-compat-tool/actions/runs/37127289306) 已完成，Windows/Linux × Python 3.10/3.12 四组测试、wheel 构建、发布包构建和 zipapp 启动均通过。后续发布流程改动和发布标签仍以各自的远端运行结果为准。
